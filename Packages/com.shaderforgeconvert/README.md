# Shader Forge Convert (Preview)

Unity Editor 2022.3 / Built-in Render Pipeline preview package. Select a Shader Forge `.shader` asset and run `Tools > Shader Forge Convert > Convert Selected Shader`.

The tool creates a new Shader asset and reports a **partial conversion**. It does not migrate materials or prove visual equivalence. See the repository README and `docs/` for status and design.
